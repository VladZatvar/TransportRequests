# TransportRequests

TransportRequests — навчальний Java-проєкт для **обліку та моніторингу заявок на автоперевезення**.
Підтримує **консольний режим** та **GUI-режим (Swing)** з таблицею, пошуком і CRUD-операціями.

## Основні можливості

### GUI (Swing)
- перегляд заявок у таблиці (JTable);
- пошук/фільтрація за: **Номер / Дата / Авто / Маршрут**;
- **додавання**, **редагування**, **видалення** заявок (з підтвердженням);
- автоматичне збереження в CSV після змін;
- підтримка двох мов інтерфейсу **UA/EN** (ResourceBundle).

### Console
- меню команд (додати/переглянути/пошук/видалити);
- збереження та завантаження даних з CSV.

## Мови інтерфейсу (UA / EN)

Проєкт використовує Java **ResourceBundle** з файлами перекладу:
- `messages_uk.properties` — українська
- `messages_en.properties` — англійська

Перемикання мови виконується кнопкою **UA/EN** у правому верхньому куті GUI.
Після перемикання оновлюються заголовки, кнопки, назви колонок таблиці та тексти діалогів.

> Примітка: файли `.properties` повинні бути збережені у кодуванні **UTF-8**.

## Збереження даних (CSV)

- Робочий файл: `requests.csv` — **створюється/оновлюється програмою** (у репозиторій не комітиться).
- Приклад формату: `requests.sample.csv`.

Колонки CSV:
- `requestNumber` — номер заявки
- `date` — дата (yyyy-mm-dd)
- `vehicle` — авто
- `route` — маршрут

CSV можна відкрити в **Excel / Google Sheets**.
