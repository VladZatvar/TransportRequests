# TransportRequests

## Опис проєкту
TransportRequests — це консольна Java-програма для обліку транспортних заявок.

Програма дозволяє:
- додавати нові заявки;
- переглядати список усіх заявок;
- шукати заявки за номером, датою або автомобілем;
- видаляти заявки;
- зберігати та завантажувати дані з CSV-файлу.

## Структура проєкту
- `src/` — вихідний код програми
- `requests.csv` — файл для збереження транспортних заявок
- `.gitignore` — список файлів і папок, які не потрібно додавати в Git
- `README.md` — опис проєкту
- `LICENSE` — ліцензія на використання коду

## Технології
- Java
- IntelliJ IDEA

## Призначення
Проєкт створений у межах навчальної дисципліни та використовується для демонстрації базової роботи з Java, CSV-файлами та системою контролю версій Git.
